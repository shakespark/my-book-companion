# 作者任务说明里每本书都一样的几节

写新书的 `source/BRIEF.md` 时，把下面几节原样放进去（`<…>` 换成这本书的），再加这本书自己的部分：读者是谁、样板抓到的错、各页提示。
`source/` 不入库，所以这份模板放在 `_tools/templates/`。

这几节是照 2026-11-15 量的数写的：Fooled by Randomness 的 18 位作者，动笔前中位数走了 47 轮、上下文 23.6 万 token，几乎每轮只发一个工具调用；
全书额度一半以上花在作者身上，其中大半是每一轮把整个上下文重读一遍。**轮数就是钱，上下文越大每轮越贵。**

---

## 怎么干活（省额度，照做）

**每一轮都把能一起发的工具调用一起发。** 你每发一轮，整个上下文就要重读一遍；一轮一个调用，是最贵的干法。

1. **第一轮**：`pwd` 确认目录，同时跑阅读包：
   ```sh
   <这本书的阅读包命令，主编在 E 步写成 tools/pack.sh>   # 例：tools/pack.sh <ID>
   ```
   它把你要读的东西（本说明以外的规范、样板骨架、LINE、你这一章的底稿、你这几节的原文和译本）切成小份，打印一张文件清单。
2. **第二轮**：在**一条消息里**用 Read 把清单上的文件**全部并行读完**。不要 `cat`、`sed -n`：超长输出会被截断存盘，还得再读一遍。
   读完就不要再回头整份重读；要找某一句用 `grep -n`。
3. **第三轮**：把要联网核的事一次列全，**一条消息里并行发出全部 WebSearch**（先调 `ToolSearch`，`query: "select:WebSearch"`，和第二轮一起发）。
   **每页不超过 8 次**（搜索结果是你上下文里最大的一项），只查「今天怎么看」和书里、底稿里没有的事实，底稿已带出处的不重查。搜不到的不追第二轮，列进报告的「拿不准」，不写进页面。
4. **图不用你找。** 这一页的照片已经由取图代理放在 `assets/img/<ID>-*.jpg`，清单在 `source/img/<ID>.md`（文件名、画面是什么、出处、图注能写什么）。
   照清单用；一张都不合用就不放照片，在报告里说要什么图。不要自己跑 `fetch_img.py`。
5. **整页一次写完**（一个 Write），不要分段追加。写完三项检查用一条命令跑：
   ```sh
   python3 -I tools/lint.py chapters/<ID>.html; python3 -I tools/overlap.py chapters/<ID>.html; node tools/check.mjs chapters/<ID>.html --shots source/shots/<ID>
   ```
   报的问题攒齐了一轮改完（几处 Edit 一起发），再跑一遍。截图切片一条消息里并行 Read。

## 硬性规则

- 只写 `chapters/<ID>.html`、有模拟器的 `tools/sim<ID>.mjs`、你的报告 `source/reports/<ID>.md`。别的文件都不改。
- 不做 git 操作，不启动常驻服务器，**不再派子代理**，**不调 advisor**（每调一次，你的整个上下文要不走缓存地重发一遍）。
- 原书材料不出 `source/` 和你的 scratchpad；运行 Python 读 `source/` 下的文件时用 `python3 -I`。
- 临时文件放你的 scratchpad 目录（**系统提示里写着路径，用你自己会话的，不要用别处抄来的路径**）下自己建的 `<ID>/` 子目录。
- 联网请求用通用的 User-Agent，不带用户的任何个人信息。grok 搜索不要调。
- **查证只到「不误导读者」为止。** 核过的事实在报告里带出处网址（审读员不重查）；凭记忆写进页面的，**全部**列进「拿不准」。
- 版权红线照公共规范。
- **交稿后就停笔**：报告写完以后不再改页面，审读员会接手。

## 交稿前回原文对一遍（审读抓到的真错，七成出在这里）

Fooled 的审读改了 131 处，46 处会让读者读歪，其中 33 处是作者回原文对一遍就能发现的。交稿前照这张单子逐条对，不必通读：

- **每一句「作者说」「书里说」**：回 `data-p` 那一段。方向反了没有，范围变了没有（一处的让步写成了整体、「过了某条线以后」这类前提丢了没有）。
  差一档语气（often 写成「常常」还是「往往」）不用纠结；**全称判断**（都、只有、必然、从不、证明了）要在原文找得到。
- **这句话是谁的**：作者转述别人的（it is said、某某认为）、他编的人物想的、本站自己推的，三样不能安到作者头上。本站的类比写「相通」「类似」，不写「就是」「是一回事」。
- **「书里没给出处」「作者没点名」**：先查书后注释（`source/text/notes.txt` 之类），有就照实写。
- **词条**：中文意思回到原文那一句核对；标「反话」「双关」的，看上下文是不是真心话。
- **卡片**（今天怎么看这类）：标题只判一句话；标签跟着「今天」栏最后一句走；「今天」栏只用出版以后的证据。
- **模拟器**：照「试试看」的顺序连点一遍，页面上写的每个数都对得上。
- **译本勘误**：只收会让读者得出错结论的；前后句已经把意思译对的不收。

## 报告

**报告落到文件 `source/reports/<ID>.md`**（主编在新会话里验收、审读员接手都靠它）：

- 动笔时建这个文件，第一行 `状态：写作中`；
- 交稿时写进完整报告（底稿见公共规范，加 `AUTHORING.md` 末尾的附加项），第一行改成 `状态：已交稿`，第二行写三项检查的结果；
- **最后一条消息只写一两句**：报告在哪个文件、三项检查过没过。不贴全文。
