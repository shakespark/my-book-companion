## 读什么

- `GLOSSARY.md`：译名表，必须照用。
- `source/text/NN.txt`：Shorey 英译，**底本**。只读你那一段，用 `[327a]` 这种斯特方节标记定位（`grep -n`、`sed -n`，或写两行 Python 按标记切出来），外加前后各一节看上下文。
- `source/text/notes/NN.txt`：Shorey 的脚注（`[^n] (节号) …`），只读你那一段的。
- `source/text/jowett/NN.txt`：Jowett 英译，没有节号，按人名和关键词找到对应段落，Shorey 费解时对照。
- `source/text/grc/NN.txt`：希腊文。术语表里的词、Shorey 和 Jowett 意思不一样的地方、否定和条件句拿不准的地方，对希腊文定。
- **不读、不找、不凭记忆照搬任何现成中译本**（郭斌和 / 张竹明、王太庆、顾寿观等）和有版权的现代英译本（Bloom、Grube / Reeve、Griffith 等）。译文只从上面三份公版文本来。也不上网搜。
- **引的荷马、赫西俄德、埃斯库罗斯等诗行**也一样：从 Shorey 和希腊文自己译，不查、不凭记忆套现成的中文荷马译本（罗念生、王焕生、陈中梅、杨宪益等）。

## 怎么译

- 意思跟 Shorey，Shorey 明显意译或含糊处跟希腊文。句子是中文的句子：读出来像人说话，不像翻译腔；Shorey 的维多利亚式长句拆开。不加原文没有的意思，不删。
- **转述体照译**：全书是苏格拉底第一人称转述（「我说」「他说」），不改成剧本体，不在行首加人名。Shorey 省掉说话人的短答（“Surely.” “Yes.”）照样不加；但中文读者分不清是谁时，可以用「他说」「我说」点明，这不算加意思。
- 一问一答要脆，口吻分得出人：克法洛斯是和气的老人，玻勒马霍斯老实，色拉叙马霍斯冲、爱挖苦，苏格拉底客气里带刺。
- 第二卷起和苏格拉底对答的是柏拉图的两位哥哥：格劳孔年轻气盛、好胜，说话痛快；阿德曼托斯沉稳、较真，对诗人和祭司那一套最不耐烦。357a–367e 是两兄弟的长篇发言，按演说体译，句子可以有气势、有铺排，但还要读得下去；不要切成一问一答的短句。
- 第三卷：386a–398b 对答的还是阿德曼托斯，398c（「格劳孔笑着说」）起换成格劳孔，到卷末。393d–394a 苏格拉底用散文转述《伊利亚特》开头（「我不是诗人，不用格律」），底本是散文，中文也排成散文。
- 论证里的关键词前后用同一个中文词（见译名表）。同一个论证里 Shorey 换了英文词而希腊文没换的，中文不换。
- 引的诗（底本里 `> ` 开头的行）译成分行的诗，同样用 `> ` 开头。诗被节标记截开时，照底本把诗行分在两节里，不整首挪进一节。底本把散文排成诗行、或把诗句夹在散文里的，中文按实际排（报告里写一句）。
- 钱、度量、官职、风俗：照译，需要解释的写成注，不在正文里夹括号解释。
- `[cit. …]` 是 Perseus 加的出处，不译、不留。

## 交什么

**`text/zh/<页>.txt`**（UTF-8）：

```
[327a]
昨天我跟阿里斯通的儿子格劳孔下到比雷埃夫斯港，……[^2]

[327b]
……
“玻勒马霍斯请你们等一等。”
我转过身，问他主人在哪儿。
```

- 你那一段的每个斯特方节标记都要有，顺序和底本一样，一个不多一个不少；标记独占一行。
- Shorey 的节常常切在句子中间。中文句子不拆：整句放进它大半落在的那一节。
- **你那一段的头尾**：跨在两页交界上的句子（比如 362c/362d、368c/368d、376c/376d）**一律归后一页**：前一页的译者在最后一节里不译它，后一页的译者整句放进自己的第一节。派活消息里会写你这一页头尾各是哪一句。
- 节内**按说话轮次换行**（一轮问或答连同它的「我说」「他说」一行），叙述另起一行。底本里的空行（分段）在中文里也空一行。
- 引号用 “ ” 和 ‘ ’。一个人的话被节标记截开时，前一节末尾不加后引号，后一节开头补前引号 “。

**注**，同一个文件末尾，`## 注` 一行之后，每条一行：`[^n] 注文` 或 `[^zN] 注文`。

- Shorey 的脚注大多是给学者的互见和文献，**只挑对门外汉读懂这句话有用的**（这人是谁、这是哪句诗、这个习俗 / 双关 / 典故是什么、这句话在回应什么），用自己的话写成中文短注（一两句），沿用 Shorey 的编号 `[^n]`，正文相应位置留 `[^n]`。没挑中的注，正文不留记号。一页大约 8–20 条。
- 你自己觉得读者需要的注（Shorey 没有的）编号 `[^z1]`、`[^z2]`…。事实要有把握，没把握的不写，列进报告「拿不准」。
- 一个中文词确实传不出原文意思、会影响读者理解论证的地方（比如「德性」用在马和刀上），加一条译注说明原词是什么意思。

**报告** `source/reports/tr-<页>.md`，第一行状态（`翻译中` / `已交稿`），然后：

- 新译名（表里没有的专名、术语，你怎么译的）。
- 没跟 Shorey、跟了希腊文或 Jowett 的地方（节号、三家各怎么说、你怎么译）。
- 拿不准的地方（节号、问题）。
- 自查结果。

## 交稿前自查

- 写个小脚本核节标记：和 `source/text/index.tsv` 里你那一段逐个对上，没有空节。
- 正文里的 `[^…]` 和 `## 注` 里的条目一一对上。
- 整段从头读一遍中文：不看英文，能不能跟上是谁在说话、在争什么。卡住的地方回去改。
- 抽五处否定句、条件句、比较句，对希腊文再核一遍方向。
