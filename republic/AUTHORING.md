# 理想国 · 对照导读：页面编写规范

公共部分见 `~/tutorials-deploy/AUTHORING-COMMON.md`，动笔前两份都要完整读。下面只写这本书的参数和差异；公共规范里的「版权红线」「英文伴读的词条」「译本」相关的几条这本书不适用，见「版权」一节。

## 这本书和它的读者

- 柏拉图《理想国》，苏格拉底第一人称转述的一场对话，十卷，斯特方码 327a–621d。现在只做第一卷（327a–354c）。
- **读者直接在站上读全文**：中文是本站新译（以 Shorey 英译为底本，对过 Jowett 和希腊文），旁边并排 Shorey 英译。读者没有纸书，没有别的中译本。所以没有「译本勘误」「页头给译本章名」「去读原书」这些东西；导读和全文在同一页，**指路就是链到全文的节**（`<a class="at" href="#s331c">331c</a>`）。
- 读者是好奇的门外汉，为乐趣读，没读过哲学。卡在四样：**论证绕、跟不上**（谁主张什么、苏格拉底怎么反驳、走到哪一步）；**希腊背景不熟**（人物、雅典当时的情况、荷马和诗人的典故）；**概念抽象**（正义、技艺、德性、功能）；**不知道今天怎么看**。
- 不怕剧透，不设分界线；不要英文词条，不接词本。

## 这本书要定的参数

## 写作依据

- 全文：中文译文 `text/zh/<页>.txt`（格式见 `tools/TRANSLATE.md`），Shorey `source/text/NN.txt`、Shorey 脚注 `source/text/notes/NN.txt`、希腊文 `source/text/grc/NN.txt`、Jowett `source/text/jowett/NN.txt`。阅读包 `sh tools/pack.sh <页>` 把这一页的 Shorey 和脚注按节切好，和译文、规范、样板一起，在一条消息里并行 Read 全部。
- **先把这一页的中文从头读一遍，再对着 Shorey 读一遍**。页面上说「苏格拉底说……」「克法洛斯认了……」，以 Shorey 为准；中文译文和 Shorey 对不上的，不改译文，写进报告「译文里看到的问题」（节号、哪里不对），主编转给译文审读。
- 人名、术语照 `GLOSSARY.md`；表里没有的写进报告「新译名」。lint 会拦住几个常见的别的译法（非正义、暴君、特拉西马库斯……）。
- **几种声音分清**：柏拉图（作者）；苏格拉底（对话里的人物，也是转述者）；对话里别的人；后来的研究者；本站。写「苏格拉底说」「柏拉图让苏格拉底说」「多数研究者认为」「本站的看法」，不混。苏格拉底在这里的话不等于柏拉图的定论，第一卷常被认为是故意没有结论的一卷。
- 余纪元《〈理想国〉讲演录》（主编要用时挂在 `source/calibre-ref`）只当背景，不搬内容、不引。

## 页面骨架

骨架照样板页抄。页头（这一卷的几页、页内跳转、上次读到哪）、顶栏的「中文 / 英文 / 对照」、页末导航、备案号和底本许可的页脚，都由 `rp.js` 注入。九节，顺序固定，写好一节就删掉那一节的「写作占位」注释和 `<p class="wip">`：

1. `读之前：这一段在争什么`（`#argue`）：`<div class="gist">`，三五句，不超过 200 个汉字。谁和谁在争什么问题、为什么值得争、读全文时盯住哪一步。别把推理过程在这里讲完。
2. `读之前：出场的人`（`#people`）：`<div class="people">` 里每人一张 `<div class="person" id="p-英文名">`，`<h3>中文名 <span class="en">English</span></h3>`、`<p class="role">`（不超过 30 个汉字）、正文不超过 150 个汉字。只写这一页说话或被点名的人；前几页介绍过的一句带过并链回去（`01a.html#p-cephalus`）。真实的人物写清是真人、生平大概；拿不准的年份不写。
3. `读之前：需要的背景`（`#background`）：每样一张 `<div class="bg" id="b-英文名">`，`<h3>`、正文不超过 200 个汉字、可选 `<p class="see">` 列出全文里用到它的节。地方、节日、风俗、钱和官职、引到的诗人和诗句、谚语、同时代的人和事（伯罗奔尼撒战争、三十僭主之类和人物命运有关的）。
4. `全文`（`#fulltext`）：**`tools/gen_text.py` 生成，不手改**。你能动的只有路标，见下。
5. `读完：论证路线`（`#route`）：`<ol class="route">`，一步一个 `<li data-kind="…">`，六类：**主张**（有人提出一个说法）、**问**（苏格拉底抛出的问题或前提）、**认**（对方认了什么）、**推出**（由前几步推出什么）、**反驳**（推出的东西和原来的主张冲突）、**插话**（不是论证的一步，但改变了局面，比如色拉叙马霍斯冲进来）。主张、问、认、插话写 `<span class="spk">人名</span>`；每步不超过 80 个汉字，用自己的话；每步至少一个 `a.at` 链回全文。一页 6–24 步；几条线时每条线前加一个 `<h3>`。前面可以有一句 `p.lede`，后面可以配一张 SVG（论证的树、两个主张的对照）。
6. `读完：概念`（`#concepts`）：1–5 块 `<div class="concept" id="c-英文">`，`<h3>中文 <span class="en">希腊文转写 · Shorey 的英文</span></h3>`，不超过 300 个汉字，可加 `<p class="use"><b>在这一页：</b>…</p>`。大白话、书外的例子；讲清这个中文词在这里和日常用法哪里不一样（「德性」用在刀和马上、「技艺」包括医术和航海、「功能」是只有它能干或它干得最好的事）。前几页讲过的链回去，不重讲。
7. `今天怎么看`（`#today`）：照抄页壳里的图例，2–4 张 `<div class="today" data-verdict="…">`，`<h4>这一步：……</h4>`（一句话，结论只判这一句）、`<p>` 后人怎么看、`<p class="src">谁说的：人名、著作或文章、年份</p>`，每张不超过 300 个汉字。四档：站得住 / 部分站得住 / 多数不买账 / 有争议。写**学界通行的看法**和有名的批评（某个论证被普遍认为偷换了概念、某个定义后来被怎样发展），点名是谁说的、在哪本书或文章里；查不到出处的不写。不推荐读者去读别的书。
8. `本站怎么看`（`#views`）：1–3 块 `<div class="views"><h4>问题</h4><p>…</p></div>`，每块不超过 400 个汉字，最后 `<p class="verdict"><b>本站的总体看法：</b>…</p>`（不超过 160 个汉字）。本站自己的评论：这段论证读下来哪里服气、哪里不服，放到今天的日常里是什么样子（记忆 views-with-commentary、reader-for-joy：别被书带歪，也别把古人当傻子）。分工：「论证路线」只讲对话里发生了什么，「今天怎么看」只讲学界，评价都在这里。
9. `精彩回顾`（`#recap`）：`<p class="recall-line"><b>一句话：</b>…</p>`，4–6 张 `<div class="item"><b>标题</b><p>…</p><a class="at" href="#s331c">331c</a></div>`。挑场面、比喻、名句（索福克勒斯说老了摆脱情欲，像逃离一个疯狂凶暴的主人），不按顺序复述。

## 全文块和论证路标

- 全文块在 `<!-- TEXT:BEGIN -->` 和 `<!-- TEXT:END -->` 之间，由 `python3 -I tools/gen_text.py <页>` 从 Shorey、`text/zh/<页>.txt` 和 `text/marks/<页>.txt` 生成；译文或路标改了就重跑。lint 核对它是不是最新的，**lint 的文字规则都跳过它**。
- 显示：每节一块，块首是节号（锚点 `#s327a`）；宽屏左中右英，手机默认只有中文，顶栏一键切「中文 / 英文 / 对照」（记在 `rp-mode-wide` / `rp-mode-narrow`）。Shorey 正文里没被译者选中的脚注和 Perseus 加的 `[cit. …]` 不显示；选中的注在中英两边显示同一个小号数字，点开在这一节下面。
- **论证路标**：`text/marks/<页>.txt`，一行一条 `节号 | 文字`，插在那一节前面，显示成标着「导读」的浅色窄条。写法：「从这里起，苏格拉底反驳的第二步：……」「色拉叙马霍斯的定义在这里第一次出现」。一条不超过 40 个汉字，只指路不下结论，**读者一眼知道这不是柏拉图的话**。一页 3–8 条，放在论证换步的地方，和「论证路线」对得上。`#` 开头的行是注释。
- 注、诗行、说话轮次的分行是译者的事；你发现排版问题（某节分行不对、注放错节），写进报告。

## 版权

- 这一卷用到的文本都是公版或开放许可：希腊文（Burnet）、Shorey 英译（Loeb 1930 / 1935，Perseus 电子版 CC BY-SA 4.0）、Jowett 英译（1892）；中文是本站新译，CC BY-SA 4.0。**全文页和导读引这几份文本都不设引用上限**，公共规范的版权红线 1–3 条不适用。署名由 `gen_text.py` 写在全文块末尾、`rp.js` 写在页脚，首页「关于底本」有全文，不用你写。
- **不看、不引任何有版权的《理想国》译本**：中文的郭斌和 / 张竹明、王太庆、顾寿观等；英文的 Bloom、Grube / Reeve、Griffith 等。也不凭记忆照搬它们的译法。「今天怎么看」可以点名研究者的观点（比如某人的专著怎么评这个论证），但不引译本的译文。
- `python3 -I tools/overlap.py chapters/<页>.html` 照跑：小壳已经让它跳过全文块和引用块、不限引用处数，剩下查的是导读正文里有没有不加引用标记、整句照搬的英文（12 词以上）。这不是版权问题：要么改成引用块，要么链到全文那一节。

## 这本书特别要守的

- **不复述对话。** 全文就在同一页，导读的任务是让读者读得懂、跟得上、读完有话说。「论证路线」是骨架不是摘要：只留论证的步子，每步一句。
- **说话人别弄错**：转述体里「他说」「我说」容易看串，写「谁认了什么」之前对着 Shorey 核一遍是谁的话。
- **别替苏格拉底把论证补圆**：他的推理有跳步、有偷换（技艺类比、「强者」的两种意思），照实画出来，毛病在「今天怎么看」「本站怎么看」里说。
- **说过头是最常见的错**：「苏格拉底证明了……」多半应是「苏格拉底让对方认了……」；对方勉强认的（「随你怎么说」）和真心认的分开。
- 希腊背景要准：年份、人物关系、钱的数目，拿不准的不写，列进报告。
- **不写相对位置**（「上一节」「前面说过」）：指路用节号链接或小节名。lint 报的「？嫌疑」逐条在报告里答：改了，或者为什么不改。

## 图

- 文件名 `<页>-小写英文名.jpg`（如 `01a-peiraeus.jpg`），只照取图清单 `source/img/<页>.md` 用；没有清单就不放照片，在报告里说想要什么。
- 适合的：地方（比雷埃夫斯、雅典卫城、长墙遗址）、物件（陶瓶上的火炬赛跑、宴饮）、人物的古代雕像（苏格拉底、柏拉图）。适合自己画的：论证的树、两种「正义」定义的对照、色拉叙马霍斯「强者」两种意思的分岔。

## 搜索

WebSearch 额度是所有代理共用的，会中途用完；**grok 不用**。每页不超过 8 次，只查「今天怎么看」点名的研究和背景里书外的事实；搜不了就列进报告的「拿不准」，不写进页面。

## 交稿前自检和报告

```sh
python3 -I tools/gen_text.py <页>                   # 改了路标就重跑
python3 -I tools/lint.py chapters/<页>.html          # 必须 ✓；「？」开头的嫌疑在报告里逐条答
python3 -I tools/overlap.py chapters/<页>.html       # 必须「全部通过」
node tools/check.mjs chapters/<页>.html --shots source/shots/<页>
```

报告 `source/reports/<页>.md`，第一行状态（`写作中` / `已交稿`），在公共规范的底稿上去掉「词条」，加：

```
人物卡 / 背景卡 / 概念：（id）
路标：几条
新译名：（没有就写「无」）
译文里看到的问题：（节号、问题；没有就写「无」）
今天怎么看：每张卡的结论和出处网址
```
