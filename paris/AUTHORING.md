# Paris to the Moon · 导读：篇目页编写规范

公共部分见 `~/tutorials-deploy/AUTHORING-COMMON.md`，动笔前两份都要完整读。下面只写这本书的参数和差异；两份有出入时以这一份为准。

## 这本书和它的读者

*Paris to the Moon: A Family in France*（Adam Gopnik，2000 年；本站用的是 Quercus 2011 年版电子书）。作者是《纽约客》的作者，1995 年秋天带着妻子 Martha 和一岁的儿子 Luke 搬到巴黎，2000 年回纽约。
全书 23 篇，分 4 部分：多数是先在《纽约客》上发表过的随笔，每部分各有一篇「圣诞日记」（Christmas Journal，第 4、8、14、19 篇；只有第 4 篇排在部分末尾），是作者每年圣诞写的私人日记，由许多短条组成，作者在第 1 篇里说它们比随笔更沉思、更悲观。
第 1 篇是全书导言，第 9 篇是 Papon 审判的长篇报道。全书约 11 万词，每篇 800–9000 词。

读者：中文母语的程序员，英文有大学四六级的底子，读过本站的几本英文伴读。**这本书以台湾译本的纸书为主读**（推测是马可孛罗版《巴黎到月球》，李桂蜜译，待读者确认），英文电子书辅助：读译本读不懂、觉得别扭时，翻英文看原文。
读者说自己卡在两样，分量相当：

- **主线**：一篇随笔从一件小事扯到法国、美国、现代性，读完说不清作者到底在说什么。
- **语言和背景**：熟词生义、反话、典故，夹在英文里的法文，作者默认读者知道的法国政治、饮食、地名、人物。

**本站没有译本的文本。** 页面不写「译本译作」「译本第几页」，不猜译本怎么译、怎么分段；人名地名用本站自己的译法，第一次出现写「中文（原文）」。
指路靠两样：读译本时认得出的**内容地标**（场面、人名、地名、东西），和英文那一节开头的几个词（读者在电子书里搜）。

## 这本书要定的参数

| 参数 | 取值 |
|---|---|
| 样板页 | `chapters/03.html`（第 3 篇 The Strike）。动笔前完整读，结构、组件、语气、密度都以它为准 |
| 页和篇 | 一篇一页，页 id 是两位篇号 `01`–`23`，`<body data-page="NN">`。`00` 是「开读之前」，主编写 |
| 小节列表 | 十节，见下，`<h2>` 文字一字不差；「后来」可省 |
| 可写的文件 | `chapters/NN.html`、自己的图片 `assets/img/NN-*.jpg`。其余只读 |
| 引用上限 | 每页 2 处，每处 25 词以内，**只引作者自己写的话**（不引 `{Q}` 段落，不引书里转述的别人的话） |
| 词条密度 | 每千词至少 4 条，一页不超过 70 条；trap 至少三分之一 |
| 图的下限 | 照片至少 3 张，自己画的 SVG 至少 1 张（「路线」那张） |
| 概述字数上限 | 「这一篇在做什么」不超过 200 个汉字 |
| 页内样式和脚本 | 不允许。SVG 用 `class="diagram"` 那套类名 |
| 报告里的附加项 | 一句话（不超过 24 个字，给目录用）；《纽约客》刊期（查到可靠出处才写，附链接）；「后来」每条的来源链接 |
| 精彩回顾 | 4–6 张卡片，每张不超过 100 个汉字；`recap.html` 自动汇总各篇的这一节 |

## 写作依据

- 原书文本：`source/text/NN.txt`（`tools/extract.py` 生成）。开头两行是篇名和所在部分。每行一段，行首 `[段号]`，文件内连续编号。
  `## §k p.页码` 是原书的分隔（电子书里的小花饰），`## §k p.页码（本站分）` 是本站给没有分隔的长篇分的节（02、15、17、21 四篇）。页码不上页面。
  段落标记：`{Q}` 缩进的引文或列表。`*词*` 是原书的斜体，多半是法文或书名。
- **先完整读完你这一篇再动笔。** 再读第 1 篇（导言）：作者在那里交代了全书的打算（在小事里找大事、拿巴黎和纽约对照、儿子的头五年对世纪的最后五年），每篇的「路线」都可以回到这些主题上。
- 读你这一篇前后各一篇的开头，知道一家人这时在什么阶段（刚到、找房、孩子上学、第二个孩子出生、准备回纽约）。书里前后呼应的地方（同一家咖啡馆、同一个人）可以在页面里指出「第 N 篇讲过」，先去那一篇原文核对。

## 页面骨架

```html
<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1">
<title>第 N 篇 · Paris to the Moon 导读</title>
<link rel="stylesheet" href="../assets/style.css">
<script src="../assets/chapters.js"></script>
<script src="../assets/pm.js"></script>
</head>
<body data-page="NN">
<main>
  …下面十节…
</main>
</body>
</html>
```

篇头（部分、篇号、原题、本站译的篇名、词数）、顶栏、篇末导航、备案号页脚、分节地图的勾选框和「词条 ↓」链接、词条的「记下」按钮和筛选栏、笔记的保存，都由 `pm.js` 注入，不要自己写。

各节顺序固定，`<h2>` 的文字一字不差：

### 1. `<h2>这一篇在做什么</h2>`
`<div class="gist"><p>…</p></div>`，不超过 200 个汉字：这一篇写的是什么时候、什么事，作者从哪件小事讲起、往哪个大题目走，读的时候抓哪两条线。
**不说结论**（结论只在「路线」的 `landing` 里说一次），不按原书顺序复述。紧跟一张照片。

### 2. `<h2>读之前：这篇的来历</h2>`
- 一段话：这一篇是在什么情况下写的（文中能看出的时间、一家人当时在什么阶段、法国当时在发生什么），在书里第几部分、前后两篇写什么。
  《纽约客》的刊期查到可靠出处才写；查不到就不提，不写「据说」。圣诞日记写明是作者的私人日记，不是专栏。
- `<div class="crux"><p>…</p></div>`：这一篇要回答的一个问题。
- `<ol class="qs">`：2–4 个带着读的问题，每个后面 `<span class="sec">§k</span>`。问要读者自己判断的事，不问能直接抄到答案的事实。

### 3. `<h2>这一篇的路线</h2>`
这一节专治「读丢主线」，也是全站最容易写成摘要的地方。写法：
- 一段话（样板约 130 字）：这一篇是怎么走的（几条线怎么交替、从哪里拉远、在哪里收回来），读译本时哪里容易觉得「突然跳了」。**讲怎么走，不讲每一步说了什么。**
- 一张自己画的 SVG：把路线摊开。随笔多半是「小事 / 大事」两条线来回（样板那样）；也可以是「巴黎 / 纽约」对照、一个比喻怎么一路变形、人物之间的关系。
  圣诞日记由许多短条组成，画「这几条线贯穿了哪些短条」（如：孩子、商店、政治各一行，标出它们出现在哪几节）。节点只写名词短语，不写结论。
- `<p class="landing"><b>作者落在哪：</b>…</p>`：**全页唯一一处说结论的地方**，不超过 130 个汉字。作者的判断写明是作者的；作者故意不下结论的，就说他停在哪个问题上。
- 整节正文（不算 SVG 和图注）不超过 380 个汉字，检查脚本会查。

### 4. `<h2>分节地图</h2>`
```html
<p class="lede">原书这一篇有 N 处分隔，分成 N+1 节……（照抄样板，按本篇改）</p>
<ol class="secmap">
  <li class="sit">第一次坐下<span>§1–§4 · 约 3200 词 · 一句话说这一段在干什么</span></li>
  <li data-sec="1"><b>中文地标<span class="w">约 1300 词</span></b><span class="en">英文开头 4–7 个词 …</span><span class="what">……</span></li>
</ol>
```
- `NN.txt` 里的每个 `## §k` 一条，一条不少，按顺序。
- `<b>`：**中文地标**，不超过 22 个汉字，写读译本时一眼认得出的东西：场面、人名、地名、店名、东西（「烤鸡停转，一街的大巴和游行」）。不写主题词（「全球化的影响」），不写结论。
- `.en`：一字不差照抄这一节第一段（不算 `{Q}`）开头 4–7 个词，后面加 ` …`。弯引号照原文。
- 词数取整到百：`awk '/^## /{if(s)print s,w; s=$2; w=0; next} /^\[/{w+=NF-1} END{print s,w}' source/text/NN.txt`
- `.what` 不超过 40 个汉字：这一节在全篇里干什么、读的时候留意什么。不把内容讲一遍。
- **本站分的节**（02、15、17、21）：`<li data-sec="k" class="ours">`，lede 里说一句「原书这一篇没有分隔，本站按内容分成 N 节（带 * 的节号）」。
- 超过 6000 词的篇用 `<li class="sit">` 分成 2–3 次坐下，每次 2500–4000 词，在意思转折处断开；6000 词以内的不分。
- 圣诞日记的节多（13–17 节），每节短：地标和 `.what` 都写短，`.what` 一句话就够。

### 5. `<h2>背景：作者默认你知道的事</h2>`
一句 `.lede`（照抄样板），然后 4–10 个 `<h3><span class="sec">§k</span>标题</h3>` 小块，按在书里出现的顺序，每块不超过 220 个汉字，尽量配图。
写美国《纽约客》读者知道、中国读者多半不知道的事：法国的政治人物和事件（1995–2000 年）、机构、法律和制度、巴黎的街区和店（第几区、哪条街、是什么样的地方）、
饮食和时装的行话、书里点名的作家艺术家和他们的作品、美国的典故（棒球、电视、政治人物）。书里点名的人用 `.who` 人物卡，一人一句：是谁、在这一篇里干什么。
书里说的和史实有出入时，一句话点出来（只在有把握时）。作者的玩笑和夸张写明是玩笑（样板里毕加索和萨特那一块）。

### 6. `<h2>词与短语</h2>`
一句 `.lede`（照抄样板），然后每一节一个小标题，下面是这一节的词条：
```html
<h3 class="sec-head" id="s2">§2 <span class="first">分节地图里这一节的中文地标</span></h3>
<div class="entry trap"><div class="en">soldier through</div><div class="loc" data-p="13">… is not to soldier through it but …</div><div class="zh">硬撑过去</div><div class="note">……</div></div>
```
- 格式见公共规范。`id="sK"` 和分节地图的节号对应；词条放在自己那一节的小标题下面，按段号排；没有词条的节不写小标题。
- **只收中文多半传不出原味的地方**，这是这本书的读法决定的：读者读的是中文，只在觉得别扭时才翻英文。四类：
  1. **熟词生义**（样板的 job action、liberal、soldier through）；
  2. **反话、挖苦、大词小用、轻描淡写**（near-insurrectionary、not quite incidentally），`.note` 点破要怎么读；
  3. **典故和文字游戏**（ghost dance、Gingrichian、merchandise 的双关），`.note` 说出处和妙处；
  4. **夹在英文里的法文**（原文的斜体），`.zh` 标「（法文）」，`.note` 说字面意思和为什么作者不用英文。
- 不收四六级词汇、词典一查就明白的生词、普通的专有名词（人名地名放「背景」）。
- `.zh` 是本站的译法，不是译本的。`.note` 一到三句，说清这里为什么难、作者的口气是什么。

### 7. `<h2>后来</h2>`（可省）
这本书写的是 1995–2000 年。书里的事后来有下文、而且下文有意思的，写 1–3 张卡片：
```html
<p class="lede">（照抄样板，按本篇改第一句）</p>
<div class="later"><h4>短标题：说的是哪件事</h4>
<p>两三句到一段，不超过 260 个汉字。<span class="asof">核对于 2026-10。依据：来源的名字。</span></p></div>
```
- **每件事都要联网核对**，写明年月；来源链接放进报告，页面上只写来源的名字。查不到下文的就不写这张卡片。
- 好的题材：书里的店和饭馆后来怎样（还开着、易主、关门）、书里的政治人物和案件的结局、书里预言过的事、法郎和欧元、禁烟这类后来变了的日常。
- 不写书里普通人（作者的家人、店员、保姆）的后来。没有好题材就整节不写。

### 8. `<h2>值得停下来的句子</h2>`
1–2 个引用块（每处 25 词以内，只引作者的话），`<cite>` 里写节号、在哪一段，和「本站译：……」。每个后面一小段：句子怎么拆、**中文译出来丢了什么**（对仗、节奏、双关、时态、口气）。挑能代表这一篇判断的句子。

### 9. `<h2>检查一下理解</h2>`
开头 `<p class="lede">先在心里答，再点开。答错的那题，回书里把对应那一节再读一遍。</p>`，5–7 题，题干标节号：
```html
<details class="check"><summary>1.（§1）问题？</summary><p>答案，两三句。</p></details>
```
问容易读丢的地方：作者的比方在比什么、这一段和全篇的关系、作者的口气是认真还是反讽。最后是 `<textarea class="note" data-key="NN-oneline">`，请读者用一句话说这一篇。

### 10. `<h2>精彩回顾</h2>`
写法照样板：
```html
<p class="lede">（照抄样板）</p>
<p class="recall-line"><b>一句话：</b>这一篇最该记住的一句话。</p>
<div class="recall">
  <div class="item"><b>烤鸡不转了</b><p>两三句。</p><span class="sec">§1</span></div>
</div>
```
- 4–6 张卡片，每张的 `<p>` 不超过 100 个汉字，标节号。
- 挑最难忘的：一个场面、一句妙语的意思、一个比方、作者的一个判断。标题短而具体，像记忆的把手（「烤鸡不转了」「火鸡的遗书」），不写空标题。
- 不按原书顺序排，不覆盖每一节。只写书里有的事。

## 这本书特别要守的

- **不替译本说话**（见上）。检查脚本会查「译本里 / 译本译作 / 译本第几页」这类写法。
- **不把页面写成中文摘要。** 读者手上有完整的中译本，页面再按原书顺序复述一遍就没有意义，也碰版权红线。
  「路线」只讲怎么走，「分节地图」只给地标和留意什么，结论只说一次；检验：只看本页，写不出一份按原书顺序的摘要。
- **作者的家人和书里的普通人**（Martha、Luke、保姆、店员、医生）只按书里写的提，不查、不配照片、不写他们后来的事。
  书里点名的公众人物（政治人物、厨师、设计师、作家）可以查、可以配照片。
- **代词**：书里有交代的（作者是 Luke 的父亲、Martha 的丈夫）可以照用；公众人物和其他没交代的人，用名字或「这位……」。
- 书里法国人说的话多半是作者译成英文的，作者也常在括号里给法文原话。词条收法文时以原文为准，不猜法国人「原本说的是什么」。
- 1995–2000 年的法国政治：总统希拉克（Jacques Chirac），总理朱佩（Alain Juppé，1995–1997）、若斯潘（Lionel Jospin，1997–2002）。写人名第一次出现用「中文（原文）」，以后只写中文或原文，全页统一。

## 交稿前自检和报告

三项检查和截图的看法见公共规范：

```sh
python3 -I tools/lint.py chapters/NN.html
python3 -I tools/overlap.py chapters/NN.html
node tools/check.mjs chapters/NN.html --shots source/shots
```

报告在公共规范的底稿上加三行：

```
一句话：（不超过 24 个字，给目录用）
《纽约客》刊期：（查到可靠出处才写，附链接；查不到写「未查到」）
后来的来源：（每张卡片的来源链接；没有「后来」写「无」）
```
